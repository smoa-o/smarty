# Support

## Getting Help

### Having trouble? Follow this order:

1. **Check the docs**: The `docs/` directory contains 4 volumes of the ISA manual; most questions can be answered there.
2. **Search Issues**: See if anyone else has encountered the same problem.
3. **Open an Issue**: If you can't find an answer, create a new one with a clear description of your problem.
4. **QQ Group**: 183241333 — there may be helpful people in the group who can assist.

### When opening an Issue, please include:

- What you did (steps)
- What you expected to see
- What you actually saw
- Simulation environment (iverilog version, OS, etc.)
- Relevant code snippets or test files

## What We Can Help With

| Type | Supported |
|---|---|
| ISA semantics questions | Yes |
| Simulation runtime issues | Yes |
| Code comprehension ("what does this code do") | Yes |
| Contribution process | Yes |
| General computer architecture instruction | Limited (recommended to check the manual first) |
| Questions unrelated to this project | No |

## What We Do NOT Provide

- One-on-one long-term mentoring
- Writing code on your behalf
- Debugging for other instruction sets / architectures

## Response Time

- Issues: Maintainers will try to respond within 7 days.
- QQ Group: Group members may answer at any time, but no guarantees.

## Reporting Security Vulnerabilities

**Do NOT open a public Issue.** Please report privately following the process in [SECURITY.md](SECURITY.md).

*This project has a learning curve, but don't be afraid to ask questions. Asking well is better than not asking at all.*
