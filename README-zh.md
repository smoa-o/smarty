# Readme - Smarty

> Smarty 技术 16 位 CISC 指令集架构与 CPU 实现，STIS.CI.16

ST-16 是一款 **专为开发者** 设计的 16 位 CISC 指令集架构——比 x86 更容易编程，
比固定宽度 RISC 更灵活。本仓库包含 Verilog CPU 实现，目标为支持操作系统运行。

Smarty 是一个可扩展的架构系列；未来计划推出 32 / 64 / 128 位变体。

## 这是什么

- **指令集架构**：自主设计的 CISC 指令集，共 4 卷规范
- **实现**: 用 Verilog 编写的 CPU 核心
- **状态**: *build1* 开发中
- **目标**: 启动操作系统
- **设计哲学**: 对开发者友好的指令编码，变长指令，无 x86 级别的复杂性

## 快速开始

### 先决条件

- **Icarus Verilog**（v0.10+）
- **GNU Make**（可选，用于构建自动化）

### 构建与测试

```bash
git clone <this-repo>
cd <this-repo>
make -j$(nproc) self-test
```

### 预期输出

最后一行应显示 `all test passed.`。
